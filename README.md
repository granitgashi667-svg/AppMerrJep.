# 🚗 Auto Kosova

Platformë moderne për import makinash nga Korea e Jugut dhe Evropa.
Faqe statike + Panel Admin me **IndexedDB** (të dhënat ruhen lokalisht në PC).

## ✨ Veçoritë
- Hero slider me Swiper.js + efekte fade
- Fontet **Oswald** (tituj) + **Montserrat** (trupi)
- Katalog me filtra (markë, vit, karburant, kërkim, sortim)
- Galeri fotosh me Lightbox (tastierë + swipe)
- Panel Admin për upload/edit/delete makinash
- Kalkulator çmimi (import + transport + doganë)
- Dizajn responsive (mobile-first)
- Të dhënat ruhen lokalisht (pa server, pa pagesë)
